# 大阪市 民泊・ゲストハウスマップ

**▶ 地図を開く: https://yyamada19241924-tech.github.io/-/**

大阪市内の民泊(住宅宿泊事業・特区民泊)と簡易宿所(ゲストハウス)の場所を地図で見るツールです。大型ホテル・旅館は含めていません。

- データ: 大阪市「[旅館業・特区民泊・住宅宿泊事業の施設等一覧](https://www.city.osaka.lg.jp/kenko/page/0000382418.html)」(CC-BY4.0)
- 地図: © OpenStreetMap contributors
- データ更新: `python tools/build_data.py` を実行して `data/minpaku.js` を作り直す
